# LLM-based agents are autonomous systems that plan, reason, and use tools while interacting with dynamic environments.

## Statement

A survey published in Findings of the Association for Computational Linguistics: ACL 2025 characterises LLM-based agents as autonomous systems that plan, reason, and use tools while interacting with dynamic environments, and treats planning and tool use as core capabilities required for agentic workflows. The survey is a peer-reviewed carrier for the agent term. The four-chapter text of 2026-07-31 grounds its own agent definition on Sapkota 2026 and Wang 2024, so the definition stands here as vault-internal checked material. The paper's further step, that the methodologically decisive variable is the span of work performed between two human interventions, is the paper's own and is not carried by this source.
