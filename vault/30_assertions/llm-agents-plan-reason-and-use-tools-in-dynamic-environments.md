# LLM-based agents are autonomous systems that plan, reason, and use tools while interacting with dynamic environments.

## Statement

A survey published in Findings of the Association for Computational Linguistics: ACL 2025 characterises LLM-based agents as autonomous systems that plan, reason, and use tools while interacting with dynamic environments, and treats planning and tool use as core capabilities required for agentic workflows. This is the first peer-reviewed carrier the paper has for its agent term, which the Agentic Engineering passage had until then set on its own authority. The paper's further step, that the methodologically decisive variable is the span of work performed between two human interventions, is the paper's own and is not carried by this source.
