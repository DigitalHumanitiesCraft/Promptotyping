# The research compendium is the established name for a repository that holds a project's data, method and output under community conventions, with the data read-only and the relation between the three made explicit.

## Statement

Marwick, Boettiger and Mullen define the research compendium by three principles that hold independently of tooling and discipline. Its files follow the conventions of the scholarly community, so that others recognise the structure and tools can build on it. It separates data, method and output while stating unambiguously how they relate, which treats the data as read-only and documents every modification in the code. And it specifies the computational environment the original analysis ran in. The arrangement is the reproducibility tradition's counterpart to a repository holding a standalone research dataset beside the code that renders it, and it names the separation the pattern already practises.
