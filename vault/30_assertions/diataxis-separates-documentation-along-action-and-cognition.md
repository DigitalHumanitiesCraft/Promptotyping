# Diataxis separates technical documentation along an action-against-cognition axis, the same cut a knowledge base makes between a declarative document and an imperative one.

## Statement

Procida derives four documentation types from two axes. The first separates action, practical knowledge, knowing how and what we do, from cognition, theoretical knowledge, knowing that and what we think, and holds the two to be counterparts that are wholly distinct. The second separates acquiring a practice from applying it. Reference is defined as propositional knowledge that is explicitly not a guide to action, and a how-to guide by the situation of an already-competent user pursuing a goal. The framework is the established, citable name for the axis along which a knowledge base splits a declarative document from an imperative one, while its second axis, study against work, presupposes a reader who acquires a skill over time and has no counterpart when the addressee is a model that loads the document per session.
