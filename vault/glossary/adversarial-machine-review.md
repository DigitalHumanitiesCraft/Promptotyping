# Adversarial machine review

An adversarial machine review is a model instructed to attack an output against its sources, interposed where data fidelity cannot be decided by a formal rule, as in OCR results, annotations, and transformations. Section 6.2 carries the definition, and Section 5.1 records its application to the paper's own figures.

The review ranks below human verification in authority and is released case by case. The term carries no external source in the paper.
