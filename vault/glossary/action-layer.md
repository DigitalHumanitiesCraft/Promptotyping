# Action layer

The action layer is the `CLAUDE.md` or equivalent configuration in the repository root that carries the implementation directives handed to the agent, including the technical guidelines of Section 4. In mature projects the file functions as agent socialisation, embedding the agent with a value system that guides decisions in unforeseen situations. Section 3.3 carries the definition.
