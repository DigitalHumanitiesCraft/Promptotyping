# Self-contained static web tool

A self-contained static web tool is a set of HTML, CSS, and JavaScript files with the research data embedded or loaded from flat files, deployable on any static host and runnable from a local folder. Section 4.1 carries the definition.

The type is the method's deliberate default within the wider genus of research artefacts, and three reasons carry it, generability in one pass by current agentic tools, publishability without infrastructure, and durability in the sense the field's sustainability discourse demands. The definition of static follows digital scholarly editing, pages that already exist as independent HTML files needing no server-side execution.

The default holds as long as its conditions hold, and this reading was fixed on 2026-07-25. The record's side forms are the cases where one condition breaks, a pipeline upstream of the artefact, a deterministically generated document, a notebook, and a Custom GPT, all of them derived from the document set in the same way.
