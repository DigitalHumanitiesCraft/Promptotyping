# Deterministically generated document

A deterministically generated document is rendered from the source data by scripts and committed alongside the hand-curated layer, a knowledge document in function and a pipeline output in production, and it is never edited by hand. Section 3.3 carries the definition, where the distinction between hand-curated and generated documents cuts across the document typology.

The motivation is the token economy. A deterministic aggregation, run once and refreshed when the source changes, produces compact descriptions that trace cleanly back to the data, which makes Distillation a build-time stage as well as a writing act. Generated documents are marked as such, in the record by their directory or by a generation header.
