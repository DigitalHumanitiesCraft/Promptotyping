# Working context

The working context is the task-specific selection of project knowledge supplied to an agent for one particular activity. It is derived from the project knowledge base and stays narrower than it, and it may hold selected documents, examples, constraints, tool instructions, current findings, and relevant data summaries. Context Engineering therefore does not mean loading all available material into a context window.

The definition stands in `knowledge/paper-specification.md` (§4.5), the definition document that governs the restructured manuscript. The canonical `research-artefacts/promptotyping-paper.md` uses the phrase once, in the token-economy passage of Section 2.2, without setting it as a term. The term carries no external source.
