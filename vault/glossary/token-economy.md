# Token economy

The token economy is the second of the two dimensions of Section 2.3, the cost in tokens of carrying data into the working context. RDF serialisations and richly encoded TEI are expensive, CSV and JSON are cheap, which reverses the ordering that [[glossary/semantic-explicitness]] sets.

The method resolves the tension by having the model read about the data and write code that reads the data. What enters the context is a distilled description, and the full data never passes through the context window. The term is the paper's own; the degradation it responds to is documented in the literature as Context Rot.
