# Implementation

Implementation is the fourth phase of the method and hands the documents to an agentic coding tool operating inside the project repository, then verifies the derived artefact along three mechanisms, deterministic feedback from schema validation, test suites, and builds, visual feedback from screenshots that enter the loop as images, and expert feedback from the Critical Expert's judgement. Section 3.2 carries the definition.

The loop from Implementation back to Distillation is the method's signature. When the artefact is wrong, the specification was wrong or incomplete, and the specification is what gets fixed before the artefact is regenerated.
