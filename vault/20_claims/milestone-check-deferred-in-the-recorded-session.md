# In the recorded session the run advances to the next milestone on a bare continuation instruction, and the artefact is inspected several milestones later.

## Statement

The recorded live demonstration works the milestones of the implementation plan one after another, and when a run stops, one of the two moves the author names is the bare `continue` that carries the procedure on inside the plan. Inspection of what was built enters afterwards, through screenshots handed to the tool because it never sees the web page, and through the browser console. At that point several milestones already stand. The claim covers the observed course of one session. Whether a verification is owed per milestone is a rule the source does not state, and the claim asserts nothing about it. Both videos are one witness, the method's author giving an account of his own practice, so this is a recorded case without independent confirmation.
