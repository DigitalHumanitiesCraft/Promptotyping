# The TEI Guidelines permit several valid encodings of one and the same textual phenomenon, so a divergence from a reference encoding is no error in itself.

## Statement

Interpretive multiplicity is a deliberate property of the TEI Guidelines, which admit more than one valid encoding of identical textual phenomena to accommodate differing scholarly perspectives and project methodologies. Two consequences follow for evaluation. Conventional similarity metrics measure divergence from a reference without being able to say whether the divergence is an error or a defensible alternative reading. And the decision between the two is an act of scholarly judgement, which places it in the verification zone of the paper's Table 2 rather than in the validation zone, however good the metric.
