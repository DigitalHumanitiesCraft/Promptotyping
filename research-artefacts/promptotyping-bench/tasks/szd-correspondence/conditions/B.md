# Compact Promptotyping working protocol

Complete the current research task using the supplied context and source policy.
Maintain a compact, inspectable project knowledge base in `knowledge/`:

1. Before implementation, record the research purpose, acceptance criteria and
   source/model assumptions needed for the task.
2. Explore the relevant records and write consequential findings back to the
   responsible knowledge document. Preserve uncertainty and source references.
3. Implement from that maintained understanding and check the artefact against
   the research task. Update the knowledge when a requirement or interpretation
   changes; distinguish proposed interpretation from source evidence.
4. At each episode boundary, leave a short handoff with the working state, checks,
   unresolved issues and next action for a fresh session.

Keep the documentation selective; about 500 words across these notes is a useful
initial target, not a scoring criterion. Avoid restating all input records. Record
what changes the next action or interpretation. File count, prose volume and
protocol compliance do not themselves earn outcome-quality points.
