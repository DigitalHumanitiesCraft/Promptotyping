# Knowledge and Project Management with Obsidian

## Context

A recorded working session that starts with an empty vault and ends with a curated one. The vault built during the session holds knowledge documents on the tooling and on knowledge modelling, and it holds the rules by which it grows, so it documents its own construction. The recording serves as introductory material for a workshop, and a written script exists alongside it as a reading version.

## Contribution

A well-structured vault is active substrate. An agent can work on it from several perspectives, and the session shows this at work, since every step is visible and the corrections are part of the recording.

The self-reference is the second point. A vault that carries the rules by which it grows can be handed to an agent without a separate briefing, and the session demonstrates the moment where that becomes true.

## Limits

The case is a demonstration. Nothing in it is a research result, and the vault it produces is a teaching artefact whose value lies in being watched being made.

The material is a recording, so it cannot be inspected the way a repository can. What a viewer sees is one path through the work, and the paths not taken leave no trace.
